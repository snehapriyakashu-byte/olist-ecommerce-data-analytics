# Olist E-Commerce Data Analytics

## Project Overview

An end-to-end e-commerce data analytics project based on the Olist Brazilian E-Commerce dataset.

The project covers data cleaning, SQL analysis, data modeling, DAX calculations, and interactive Power BI dashboard development.

## Tools & Technologies

- Microsoft Excel
- MySQL
- Power BI
- DAX

## Project Workflow

Excel Data Cleaning
→ SQL Analysis
→ Power BI Data Modeling
→ DAX Calculations
→ Interactive Dashboard

## Key Analysis

- Sales and revenue performance
- Monthly revenue trends
- Product category performance
- Top-performing products
- Customer behavior and segmentation
- Payment methods
- Delivery performance
- Customer review scores
- Order status analysis

## Data Modeling

A relational data model was created in Power BI connecting orders, customers, products, sellers, payments, reviews, and product categories to support interactive analysis.

## SQL Analysis

SQL was used to analyze sales performance, customer behavior, product performance, delivery performance, payment methods, reviews, and order status.

## Business Insights

- Revenue performance was analyzed across different months and product categories.
- Top-performing categories and products were identified based on revenue.
- Customer behavior was analyzed using one-time and repeat customer segments.
- Delivery performance was evaluated using on-time and late deliveries.
- Payment methods were compared based on payment value.
- Customer review scores were analyzed to understand customer satisfaction patterns.

## Business Recommendations

- Focus on high-revenue product categories and monitor their performance.
- Investigate products and categories with lower sales contribution.
- Encourage repeat purchases through customer retention strategies.
- Monitor late deliveries and identify opportunities to improve logistics.
- Track customer reviews to identify areas for service improvement.
